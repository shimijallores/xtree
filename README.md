# XTree

Version 1.0.0

## Introduction

XTree is a local-first, UML-driven code comprehension engine engineered for vibe coders and software engineers navigating unfamiliar or agent-generated codebases. Built on Bun, the TypeScript Compiler API, React, Motion, and Ollama, the platform bridges deterministic static analysis with on-device AI inference (`qwen2.5-coder:3b`). XTree enforces a core architectural principle: the parser is the single source of truth for code structure, while the local LLM provides plain-language understanding. Code never leaves your machine, eliminating third-party cloud API costs, latency bottlenecks, and proprietary code privacy concerns.

## Features

### Deterministic Static Analysis and Symbol Extraction

- Deep AST traversal powered by the TypeScript Compiler API, following imports up to depth 2 from any selected entry file.
- Comprehensive symbol extraction capturing classes (constructors, fields, methods, accessibility modifiers, `#private`), functions, arrow functions, interfaces, type aliases, and enums.
- Explicit relationship classification mapping `calls` (numbered in sequential execution order), `contains`, `uses-type`, `extends`, `implements`, and `imports`.
- First-class support for modern JavaScript and TypeScript patterns including JSX components, `React.memo`, `forwardRef`, and CommonJS modules.
- Unresolved external references are modeled as distinct stubs without hallucinating non-existent internal symbols.

### Dual-Engine Visualizer: Interactive UML Canvas and Radial Relationship Graph

- Interactive SVG UML class and component diagram rendering with bottom-up hierarchical layout, auto-connecting ports, and clean orthogonal routing.
- Radial dependency and relationship graph view providing top-level topological navigation across file boundaries and symbol clusters.
- Real-time symbol selection with side inspector cards displaying signatures, source code snippets, and active dependency links.
- Interactive controls including zoom, pan, fit-to-screen, search filtering, and an onboarding walkthrough tour.

### Local AI Explanations, Flow Walkthroughs, and Grounded Chat

- Streaming card summaries generated by Ollama (`qwen2.5-coder:3b`), prioritizing symbols breadth-first along execution paths.
- Deterministic content-addressed caching in `.xtree/cache.json` indexed by `sha256(source + model + prompt_version)` to prevent redundant re-summarization.
- Explain Flow engine combining static call graph sequencing with model-written step-by-step walkthroughs.
- Grounded contextual chat drawer limited to pinned symbols and immediate neighbors, preventing hallucinations and keeping prompt context under 6k tokens with clickable symbol chips.

### Live File Watching and Incremental Graph Updates

- High-performance Chokidar file watcher honoring `.gitignore` rules with debounced event batching.
- WebSocket-driven incremental diffing (`graph.diff`) that dynamically updates nodes and edges without forcing manual browser reloads.
- Visual change indicators highlighting updated cards with badges that automatically decay after 10 seconds.
- Resilient error handling that retains the last-valid AST state if an in-progress file edit introduces syntax errors.

## Architecture

XTree is organized as a Bun monorepo comprising a backend engine, a single-port local server, and a React web application.

### Technology Stack

- Runtime & Package Manager: Bun 1.4.2
- Server & Parser: TypeScript 6.0.3, TypeScript Compiler API, Chokidar, Commander
- Web Framework & UI: React 19, Motion (`motion/react`), Zustand 5, Lucide Icons, Vite
- Inference Runtime: Ollama (`qwen2.5-coder:3b`)
- Testing: Bun Test Runner (`bun test`)

### Data Flow

1. **Project Scan and Entry Point Selection**: The user selects a target project, prompting [`scan()`](file:///c:/Users/Patriach/Downloads/appbuilders/xtree_v0/server/src/scanner.ts#L68) in [`server/src/scanner.ts`](file:///c:/Users/Patriach/Downloads/appbuilders/xtree_v0/server/src/scanner.ts) to index supported files while skipping `.gitignore` entries and large build directories.
2. **AST Static Extraction**: When an entry file is chosen, [`Analyzer`](file:///c:/Users/Patriach/Downloads/appbuilders/xtree_v0/server/src/analyzer/index.ts#L40) in [`server/src/analyzer/index.ts`](file:///c:/Users/Patriach/Downloads/appbuilders/xtree_v0/server/src/analyzer/index.ts) parses the import closure with [`extractSymbols()`](file:///c:/Users/Patriach/Downloads/appbuilders/xtree_v0/server/src/analyzer/symbols.ts) and builds deterministic call and type edges via [`buildEdges()`](file:///c:/Users/Patriach/Downloads/appbuilders/xtree_v0/server/src/analyzer/callGraph.ts).
3. **Session Management and WebSocket Broadcast**: [`Session`](file:///c:/Users/Patriach/Downloads/appbuilders/xtree_v0/server/src/session.ts#L25) manages active graph state in [`server/src/session.ts`](file:///c:/Users/Patriach/Downloads/appbuilders/xtree_v0/server/src/session.ts) and serves HTTP/WebSocket traffic through [`server/src/server.ts`](file:///c:/Users/Patriach/Downloads/appbuilders/xtree_v0/server/src/server.ts), pushing graph structures to the web client.
4. **Local LLM Streaming and Caching**: [`LlmService`](file:///c:/Users/Patriach/Downloads/appbuilders/xtree_v0/server/src/llm/service.ts#L58) queues requests to [`OllamaClient`](file:///c:/Users/Patriach/Downloads/appbuilders/xtree_v0/server/src/llm/ollama.ts#L10), checking the content-hash disk cache before streaming plain-language summaries and flow descriptions to the UI.
5. **Interactive UI Visualization**: [`App`](file:///c:/Users/Patriach/Downloads/appbuilders/xtree_v0/web/src/App.tsx) renders the visual canvas via [`UmlCanvas`](file:///c:/Users/Patriach/Downloads/appbuilders/xtree_v0/web/src/components/uml/UmlCanvas.tsx) or [`GraphCanvas`](file:///c:/Users/Patriach/Downloads/appbuilders/xtree_v0/web/src/components/graph/GraphCanvas.tsx), backed by Zustand state in [`web/src/store.ts`](file:///c:/Users/Patriach/Downloads/appbuilders/xtree_v0/web/src/store.ts).

## Getting Started

### Prerequisites

- [Bun](https://bun.sh/) 1.3.0 or higher
- [Ollama](https://ollama.ai/) with `qwen2.5-coder:3b` pulled (optional; only required for summaries, flow walkthroughs, and chat)

```bash
ollama pull qwen2.5-coder:3b
```

### Installation

Clone the repository and install dependencies:

```bash
git clone <repository-url>
cd xtree
bun install
bun run build
```

### Running the Application

Launch XTree against the included demo project or any target JavaScript/TypeScript directory:

```bash
# Start XTree on the sample e-commerce application
bun bin/xtree.js start examples/shop-app

# Or inspect the current working directory
bun bin/xtree.js start .

# Launch with frontend hot reload for development
bun run dev
```

### Running Tests

Execute the automated test suite and type check:

```bash
# Run server test suite
bun run test

# Run TypeScript typechecks across workspaces
bun run typecheck
```
